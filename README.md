# Agenda de Contatos

Aplicação em Python, feita em dupla, para cadastrar, listar, buscar e remover contatos via terminal.

## Funcionalidades

- Cadastrar um novo contato (nome, telefone e email)
- Listar todos os contatos cadastrados
- Buscar um contato pelo nome
- Remover um contato

## Como executar

É necessário ter o Python 3 instalado. No terminal, dentro da pasta do projeto, execute:

```bash
python agenda.py
```

Para executar os testes:

```bash
python -m unittest -v
```
